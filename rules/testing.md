# Testing Requirements

## Minimum Test Coverage: 80%

All three tiers required: unit, integration, and Playwright E2E for critical user flows.

## Rules

- Test-first (RED → GREEN → REFACTOR) for new features and bug fixes.
- Fix the implementation, not the test — unless the test is provably wrong.

## Agent Support

- **tdd-guide** — use PROACTIVELY for new features; enforces write-tests-first
- **e2e-runner** — Playwright E2E specialist
