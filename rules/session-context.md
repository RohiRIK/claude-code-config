# Session Context Persistence

Per-project context lives in `~/.claude/memory/ltm.db` (managed by the `~/.claude/memory/*.ts` modules and hooks). Global LTM memories live in the openltm plugin DB at `~/.claude/plugins/data/OpenLtm-openltm/openltm.db`. Hooks manage both automatically — Claude does NOT write context files.

## Context Types

| Type | Purpose |
|------|---------|
| `goal` | Current objective (1-3 lines) |
| `decision` | Architectural choices — permanent |
| `progress` | Session log — trimmed to last 20 |
| `gotcha` | Warnings, pitfalls — permanent |

## Short-Term vs Long-Term

| Question | Store as |
|----------|----------|
| Specific to current project? | context_item (auto-managed) |
| Useful in ALL future projects? | `/learn` (global memories) |
| Permanent rule or gotcha? | `/learn --importance 5` |

Short-term context expires after 14 days inactivity. Global memories persist forever.

## Rules

- Never manually write to `context-goals.md`, `context-decisions.md`, `context-progress.md`, or `context-gotchas.md`
- Never manually edit `context-summary.md` — it is auto-generated by PreCompact hook
- Use `mcp__plugin_openltm_memory__learn` to persist important insights to global LTM
- Use `mcp__plugin_openltm_memory__recall` before starting non-trivial tasks
