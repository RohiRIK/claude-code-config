# TypeScript Starter Templates

Curated GitHub templates for scaffolding new TypeScript/Bun projects.

| Template | Repo | Use When |
|---|---|---|
| Bun CLI | [khalidx/typescript-cli-starter](https://github.com/khalidx/typescript-cli-starter) | CLI tool with Bun runtime, cross-platform |
| Hono REST API | [ProMehedi/bun-hono-rest-api](https://github.com/ProMehedi/bun-hono-rest-api) | REST API with Bun + Hono + Zod + JWT |
| Full-stack monorepo | [hbinduni/bun-hono-react-monorepo](https://github.com/hbinduni/bun-hono-react-monorepo) | Hono API + React frontend + shared types, Turborepo |
| Bun library | [galligan/bun-monorepo-starter](https://github.com/galligan/bun-monorepo-starter) | Publishable npm/JSR package with Bun + Turbo |

## Quickstart

```bash
# CLI tool
git clone https://github.com/khalidx/typescript-cli-starter my-cli
cd my-cli && bun install

# Hono API
git clone https://github.com/ProMehedi/bun-hono-rest-api my-api
cd my-api && bun install && bun dev

# Full-stack monorepo
git clone https://github.com/hbinduni/bun-hono-react-monorepo my-app
cd my-app && bun install && bun dev
```
