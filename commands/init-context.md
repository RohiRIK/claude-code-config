# Init Project Context

Seed a new project's initial goal into the SQLite LTM DB (`~/.claude/memory/ltm.db`).

## When to Use

Run for a **new project** that has no context in the DB yet. For existing projects, use `/update-context` or `/learn` instead.

## Steps

### 1 — Verify project is registered

```bash
cat ~/.claude/projects/registry.json
```

Find the entry matching the current `cwd`. If missing, run `/register-project` first, then return here.

### 2 — Check if goal already exists

```bash
bun -e "
  const { getItems } = await import(\`\${process.env.HOME}/.claude/memory/context.js\`);
  console.log(JSON.stringify(getItems('PROJECT_NAME', 'goal')));
"
```

If a goal exists, display it and ask: "A goal already exists — do you want to replace it?"

### 3 — Ask for the initial goal

Prompt the user:
> "What is the current goal for **PROJECT_NAME**? (1-3 bullet points, max 100 chars each)"

Wait for their answer.

### 4 — Seed goal into DB

```bash
bun -e "
  const { addItem } = await import(\`\${process.env.HOME}/.claude/memory/context.js\`);
  addItem('PROJECT_NAME', 'goal', 'USER_GOAL_CONTENT');
  console.log('done');
"
```

### 5 — Confirm

```
Project **PROJECT_NAME** seeded in ltm.db.
Goal: <goal content>

Decisions, progress, and gotchas will accumulate automatically via hooks.
Use /learn to add important global insights.
```

## Notes

- Do NOT create `context-goals.md`, `context-decisions.md`, `context-progress.md`, or `context-gotchas.md` — the DB is the source of truth
- `context-summary.md` will be auto-generated by the `PreCompact` hook at next compaction
- If `ltm.db` does not exist yet, the `addItem()` call will create it automatically
